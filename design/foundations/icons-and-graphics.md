# 图标与图形资源规则

> 来源：原 DESIGN.md §7 ｜ 取值数据来源：`src/styles/tokens.css` ｜ 返回索引：[design/DESIGN.md](../DESIGN.md)

## 概述

线性几何图标，统一线宽 1.6px、圆角端点（`stroke-linecap: round`、`stroke-linejoin: round`）。无装饰插画、无照片。outline 为默认，filled 仅用于激活 / 选中态（filled 用 `var(--accent)` 色）。数据可视化有独立色板（见 [colors.md](colors.md) 数据可视化分类色板），不与图标色混用。

## Token 引用

| Token | 用途 |
|---|---|
| `currentColor` | 图标颜色随上下文文字色 |
| `var(--accent)` | 激活 / 选中态 filled 图标 |
| `var(--viz-1)` … `var(--viz-6)` | 数据可视化专用（不用于图标） |

## 规则细则

### 风格规格

- **描边**：`stroke-width: 1.6px`，`fill: none`，端点圆角。
- **网格**：24×24 viewBox，像素对齐。
- **颜色**：继承 `currentColor`（随上下文文字色）；激活态 filled 用 `var(--accent)`。
- **不加阴影、不加渐变**：图标是符号，不是插画。
- **零外部图形资源**：所有矢量图形（图标、图示、流程图、数据可视化、装饰图形）一律**内联 SVG** 手绘，不引入外部图标库（Font Awesome / Lucide 包等）、不引用图片文件、不引用外部 SVG。图形随构建产物自包含。

### 尺寸档

| 尺寸 | 用途 |
|---|---|
| 14px | 行内、标签内、密集表格 |
| 16px | 按钮内 |
| 20px | 默认 |
| 24px | 容器标题、空状态 |

### outline vs filled

- **outline（默认）**：所有功能符号的静止态。
- **filled（仅激活 / 选中）**：当前选中项、已收藏、激活开关。filled 形态用 `var(--accent)` 色，不用中性灰。

### 图像策略

- 代码截图 / 终端输出放 12px 圆角（`--r-lg`）边框容器，等宽字体。
- 集成 logo 以简单图标网格呈现，单色优先。
- 数据可视化用分类色板（`--viz-*`），避开界面绿。
- 禁止：装饰性插画 / 吉祥物、照片素材、彩色渐变图标、混用线宽与端点、为图标加阴影。
- 禁止：引入外部图标库 / 图标字体 / 图片文件 / 外部 SVG 资源（见下节）。

### 图形资源策略（零外部资源）

- **一切矢量图形内联 SVG**：图标、流程图、架构图、状态图、数据可视化、装饰线条，全部以内联 `<svg>` 在组件中绘制。
- **不引入**：外部图标库、图标字体（icon font）、PNG/SVG/WebP 图片文件、外部 SVG 引用、sprite 图集。
- **理由**：自包含、可随主题 token 着色（`currentColor` / CSS 变量）、无网络请求、无版本依赖、可精确控制线宽与几何对齐。
- **例外**：用户上传内容（如截图）属数据，不属设计系统图形范畴。
- **Web 字体**：Manrope / Fira Code 当前经 Google Fonts CDN 加载——若要求全站零外部资源，改自托管字体（`@font-face` + 本地 woff2），或回退系统字体。此项待定（见索引裁决与迁移记录）。

## Do's & Don'ts

**Do**

- 图标统一 1.6px 线性几何；outline 默认、filled 仅激活态。
- 所有矢量图形内联 SVG；图标经 `src/components/ui/Icon.tsx` 内联 SVG 注册表提供。

**Don't**

- 不使用装饰性插画 / 吉祥物 / 照片；不用彩色渐变图标。
- 不混用多种线宽与端点风格；不为图标加阴影。
- 不引入外部图标库 / 图标字体 / 图片文件 / 外部 SVG。
