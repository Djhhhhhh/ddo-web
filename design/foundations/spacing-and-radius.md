# 间距与圆角规则

> 来源：原 DESIGN.md §5 ｜ 取值数据来源：`src/styles/tokens.css` ｜ 返回索引：[design/DESIGN.md](../DESIGN.md)

## 概述

间距以 **8px 为 base 的离散标度**，仅取标度内值，不连续取值（禁止 7px、11px 这类标度外值）。圆角仅 6/8/12px 三档。留白即层级——section 间用大间距区隔，组件内用小间距成组。

## Token 引用

| Token | 用途 |
|---|---|
| `var(--s1)` … `var(--s14)` | 间距标度（14 档） |
| `var(--r-sm)` / `var(--r-md)` / `var(--r-lg)` / `var(--pill)` | 圆角标度 |
| `var(--container)` | 容器最大宽度 |

## 规则细则

### 间距标度

| Token | 值 | 用途 |
|---|---|---|
| `--s1` | 4px | 标签内、图标与文字 gap |
| `--s2` | 6px | 徽章内 gap |
| `--s3` | 8px | base · 行内基础、组件内 gap |
| `--s4` | 10px | 按钮上下 padding |
| `--s5` | 12px | 密集输入上下 padding |
| `--s6` | 14px | 小容器内边距 |
| `--s7` | 16px | 组件间 gap |
| `--s8` | 20px | 栅格 gutter |
| `--s9` | 24px | 卡片内边距 |
| `--s10` | 32px | 区块内 gap |
| `--s11` | 40px | 区块上下 |
| `--s12` | 48px | 大区块上下 |
| `--s13` | 64px | section 间 |
| `--s14` | 80px | 页面顶 / 底 |

### 圆角标度

| Token | 值 | 用途 |
|---|---|---|
| `--r-sm` | 6px | chip / tag / 小控件 |
| `--r-md` | 8px | 按钮 / 输入 / Tabs 容器 / 内嵌面板 |
| `--r-lg` | 12px | 卡片 / 面板 / 代码块 / 表格外框 |
| `--pill` | 9999px | **仅 switch**，不用于按钮 / 标签 |

> 圆角三档传达容器层级：小→chip，中→控件，大→容器。不引入 4px、16px 等中间值。

### 栅格与容器

- 容器最大宽度 `var(--container)`（1080px），居中。
- 12 列栅格，gutter `var(--s8)`（20px）。
- 内容左右留边随视口缩放，移动端折叠为单列（见 [responsive.md](responsive.md)）。

### 留白哲学

- **section 间垂直 64px**（`--s13`），用大留白区隔概念，不靠分割线。
- **区块内**用 24–32px（`--s9`–`--s10`）成组。
- **组件内**用 4–12px（`--s1`–`--s5`）紧凑成组。
- 页面顶 / 底留 80px（`--s14`）。
- 留白即层级：间距大小本身传达“这是同一组 / 这是新章节”，减少对边框的依赖。

## Do's & Don'ts

**Do**

- 间距只取 `--s1`–`--s14` 标度内值；圆角只用 `--r-sm` / `--r-md` / `--r-lg`。
- 用间距层级表达分组与章节关系。

**Don't**

- 不用标度外的间距值（如 7px、11px）；不用 4px / 16px 等中间圆角。
- 不用 `--pill` 圆角做按钮 / 标签（仅 switch）。
- 不靠堆叠分割线分区（优先留白与背景位移）。

## AI 实现检查清单

- [ ] 所有 margin / padding / gap 值可映射到 `--s*` 档位。
- [ ] 所有 `border-radius` 为 `--r-sm` / `--r-md` / `--r-lg`（switch 除外用 `--pill`）。
- [ ] 容器最大宽度使用 `var(--container)`。
- [ ] 页面级区块间距 ≥ `--s13`，组件内间距 ≤ `--s5`。
