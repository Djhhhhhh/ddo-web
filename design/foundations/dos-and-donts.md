# 全局 Do's & Don'ts

> 来源：原 DESIGN.md §8 ｜ 返回索引：[design/DESIGN.md](../DESIGN.md)

## 概述

本文件是全局 Do / Don't 的总集；与各组件 / 领域强相关的条目同时收录在对应规则文件的 Do's & Don'ts 节。新增组件前先回看本文件；觉得装饰过多就删——技术精确型里少即是多。

## Do

- 用 dark 为默认主题，light 为同等一等公民，二者共用同一套中性蓝灰阶 + 绿信号色。
- 界面里同时只允许一种彩色（`--accent` 绿）说话；语义色仅在状态出现时点缀。
- 信号色只用于可操作 / 最重要元素：主操作、链接、可点标签、焦点环、数据强调。
- 用 Manrope 承载所有 UI 文本，Fira Code 承载代码 / 数据 / ID / 时间戳。
- 字重只用 400 / 500 / 600；数字一律等宽 + `tabular-nums`。
- 控件走统一高度标度（sm 28 / md 36 / lg 44px），按钮与输入同尺寸等高。
- 间距只取间距标度内值；圆角只用 6 / 8 / 12px（pill 仅 switch）。
- 正常态靠背景色位移与 1px 边框分层；阴影仅用于 e1–e3 浮起 / 卡片 / 弹层。
- 焦点统一用 `--accent-ring` 3px 环（`focus-visible`）。
- 图标统一 1.6px 线性几何；outline 默认、filled 仅激活态。
- 搜索 / 命令入口统一用命令栏形态（等宽 + 左图标 + 右 ⌘K）。

## Don't

- 不引入第二种界面彩色；不把信号色当背景大面积铺、不当正文色。
- 不用字重 700+；不混用第二套展示字体。
- 不用标度外的间距值（如 7px、11px）；不用 4px / 16px 等中间圆角。
- 不用 pill 圆角做按钮 / 标签（仅 switch）。
- 不用重投影、拟物高光、品牌渐变；不用阴影表达焦点。
- 不使用装饰性插画 / 吉祥物 / 照片；不用彩色渐变图标。
- 不混用多种线宽与端点风格；不为图标加阴影。
- 不在亮色模式下把代码块变浅（代码块恒暗）。
- 不用下划线式 tabs；激活态靠浮起小卡，不靠下划线。
- 不引入外部图标库 / 图标字体 / 图片文件 / 外部 SVG；所有矢量图形内联 SVG（见 [icons-and-graphics.md](icons-and-graphics.md)）。
- 不用浏览器默认滚动条；不用 `--accent` 染色滑块。滚动条收编为中性半透明细条（见 [../components/scrollbar.md](../components/scrollbar.md)）。

## 迭代守则

1. 每次只改一个组件 / 一个 token，改完在 dark 与 light 两套主题下各看一遍。
2. 颜色只引用命名角色（“accent”、“surface-1”），不写裸 hex；改值只改 token 定义处（`src/styles/tokens.css`）。
3. 间距 / 圆角只取标度内值；控件高度只取 sm / md / lg。
4. 字重只取 400 / 500 / 600；数字一律等宽 + `tabular-nums`。
5. 新增组件前先回看本文件 Do / Don't；觉得装饰过多就删——技术精确型里少即是多。
6. 信号色是全界面唯一彩色；任何想引入新色的冲动，先问“能不能用现有中性阶 + `--accent` 表达”。

> 样式变更沉淀流程（git push 前提示）见 `../../AGENTS.md` 开发流程节与 [../DESIGN.md](../DESIGN.md) 迭代守则。
